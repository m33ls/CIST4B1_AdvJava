# Linked Lists
## List ADT
* What do we mean when we talk about a list?
    * E.g. arrays
* Specific properties
    * Ordered: Elements in a list are added in a specific sequence and can be accessed in the same sequence
    * Null Elements: Null elements can be stored as distinct elements in a list
    * Duplicate elements: elements are allowed to be duplicates of other elements in a list without being the same element

## Introduction
* Linked list
    * Constructed using objects
        * Comprised of data and object reference
        * Object references point to each next, linking the list
    * Grows and shrinks during run-time
    * Doubly Linked List: A variation with pointers in both directions

* Objects backbone of such structures
* Trees also use objects
* Python list
    * Not a linked list, basically a dynamically sized array

```java
// Node.java

public static void main(String[] args) {
/* Create Node
 * Integer example
 */
 Node<Integer> newNode = new Node<Integer>(23);
 Node<Integer> newNode2 = new Node<Integer>(26);
 Node<Integer> newNode3 = new Node<Integer>(21);

 newNode.next = newNode2;
 newNode2.next = newNode3;

 System.out.println(newNode.data);
 System.out.println(newNode.next.data);
 System.out.println(newNode.next.next.data);
 

}

public class Node<T> {
    // Data
    public T data;
    // Link
    public Node next;

    Node(T data){
        this.data = data;
        this.next = null;
    }
}
```
