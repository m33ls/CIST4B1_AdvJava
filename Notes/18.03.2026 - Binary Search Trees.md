# Binary Trees
## Search
* Binary search trees lendn themselves naturally to searching
    * Its in the name
* We can follow the binary search algorithm, adapting it for traversal through a tree
* Start at root.
* Compare
    * If equal -> ret
    * If less than go left
    * If greater than go right
* Repeat until found or exhausted

## Search Efficiency
* In a balanced BST, O(log n)
* Worst case; essentially linked list, O(n)

## Deletion Algorithm
* Removing a node is much more complex than searching or inserting, only really simple when you remove a leaf node
1. locate the Node via search
2. Check possible node deletion case
    * If the node is a leaf, remove it
        * Disconnect parent's link to it (= null)
    * If the node has one child, link the node's parent to that child
    * If the node has two children, find the in order successor ( the smallest value in the right subtree) and replace the value of the node to be deleted with the value of the inorder successor. Then, recursively delete the in order successor

## Tree Traversal
* In order
    * Left, Node, Right
* Preorder
    * Top -> Bottom
    * Left -> Right
* Postorder
    * Bottom -> Top
    * Left -> Right

## Inorder Traversal
* Steps
    * Traverse down left subtree
    * Visit root
    * Traverse down right subtree
* Usage
    * In a BST, visits nodes in ascending order of their value

## Preorder Traversal
* Steps
    * Visit the root
    * Traverse down left sub tree
    * Traverse down right sub tree
* Usage
    * Using pre order traversal, it is possible to create a copy of the BST since you are visiting the nodes in the order in which they would be added

## Postorder
* Steps
    * Traverse the left subtree
    * Traverse the right subtree
    * Visit the root
* Usage
    * While not as important in java, post order traversal is helpful in deleting the tree while not accidentally unlinking any node and causing a memory leak.
